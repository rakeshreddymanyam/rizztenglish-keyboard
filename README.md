# RizzTenglish Native Android Default Keyboard

## How to Build the `.apk` on Your Laptop & Install on Mobile

1. Extract this ZIP file on your laptop.
2. Open **Android Studio** -> **Open** -> select the extracted `RizzTenglishKeyboard` folder.
3. Wait for Gradle to sync (if prompted to generate Gradle Wrapper, click **OK**).
4. Go to **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
5. Copy `app/build/outputs/apk/debug/app-debug.apk` to your Android phone and install it.
6. Open **RizzTenglish Keyboard** on your phone:
   - Paste your Gemini API key and tap **Save API Key**.
   - Tap **1. Enable RizzTenglish in Settings** and toggle it ON.
   - Tap **2. Switch Default Keyboard to RizzTenglish**.
7. Open WhatsApp, Instagram, or any app—**RizzTenglish Keyboard** will pop up automatically whenever you type!
